### 新增

- **轮次耗时**：派发页状态条在回合进行中实时累计「已用 1m07s」，回合结束定格为「本轮 1m07s」，同一数字同时写进该轮 Claude 消息头（紧跟时间戳），往回翻即可看出本次会话里哪几轮是重活；超过 5 分钟的轮次在消息头上调一级色阶。耗时取后端 `result` 事件的权威值（与终端同源），故只覆盖本次实时跑过的轮次——接回或回放的历史轮次仍不显示耗时。
