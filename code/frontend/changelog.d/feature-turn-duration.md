### 新增

- **轮次耗时**：派发页状态条在回合进行中实时累计「已用 1m07s」，回合结束定格为「本轮 1m07s」，同一数字同时写进该轮 Claude 消息头（紧跟时间戳），往回翻即可看出本次会话里哪几轮是重活；超过 5 分钟的轮次在消息头上调一级色阶。
- **耗时口径**：本前端发出的轮次按墙钟计（按下发送 → 回合结束），故状态条数到的秒数与定格值连续；接回观战、刷新后装载的历史轮次没有本地起点，退回 SDK 的 `duration_ms`。会话 jsonl 不记录轮次耗时，刷新后既往轮次的消息头不再显示耗时。

### 变更

- **状态条让位规则**：状态文字变长后整行放不下时，改由会话标识先收缩（它有 ellipsis 兜底，会话名从卡片与标题栏都能看到），状态里的耗时与成本优先保完整，不再把 `$0.53` 截成看着像 `$0` 的半个数字；窄窗仍按原有规则折行（≤960px）或横滑（≤430px）。
