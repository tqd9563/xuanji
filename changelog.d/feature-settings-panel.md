### 新增
- **统一设置入口**：新增设置对话框的获批原型 `wiki/design/prototype-settings.html`，侧栏底部齿轮或 `⌘,` 打开，含派发 / 外观 / 快捷键 / 通知 / 高级五个分区、跨分区搜索与按分区恢复默认。原型为居中大框形态（900×640），复用既有 `.modal` 词汇。

### 变更
- **设计规范收录设置面板**：`DESIGN.md` 增补设置对话框组件规范与 `settings-*` / `keycap` token，并新增一条 Do —— 任何用户偏好都必须经统一设置入口暴露且显式标注存储范围（「本机」localStorage /「账户」后端 `meta` 表），禁止在功能页面里就地长出第二个设置入口。壁纸段的入口描述随之从侧栏上弹面板改为设置对话框的「外观」分区，三档模式与四个参数的既有规范不变。

### 修复
- **设置里的下拉不再用原生 select**：四个下拉（默认模型 / 思考深度 / 权限模式 / 工作目录）改用既有自绘下拉的模态内变体，语义着色与派发页底栏一致（模型紫、工作目录蓝）；原生弹层由操作系统绘制，蓝底高亮无法主题化。

### 新增
- **设置面板落地**：侧栏底部齿轮或 `⌘,` 打开统一设置，含派发 / 外观 / 快捷键 / 通知 / 高级五个分区与跨分区搜索。派发默认值（模型、思考深度、权限模式、工作目录、转后台、任务总结触发语）与通知范围存后端并跨设备同步；外观与快捷键存本机。移动端从「更多」进入同一面板。
- **快捷键可改**：全站键位集中成一张表，设置里可逐项改键，与已有键位冲突会标黄写明与谁冲突，不静默覆盖。Esc / 方向键等控件语义键以只读行呈现。
- **发送键可切**：新增「Enter 发送 · ⇧⏎ 换行」一档，默认仍为 PR#45 起的 `⌘⏎ 发送 · Enter 换行`。
- **正文字号与减少动效**：字号三档走 root font-size 整站等比；减少动效可显式开关，默认跟随系统。

### 变更
- **默认工作目录不再总是列表首项**：未显式选择时优先用设置里的默认目录，该目录已从 `~/.claude/projects` 消失时才退回首项。
- **壁纸入口并入设置**：侧栏底部的壁纸按钮与上弹面板改为设置对话框的「外观」分区，三档模式与四个参数及其默认值不变；移动端「更多」里的壁纸行改为「设置」并真正可用（原先只吐一句「后续迭代」）。
- **通知按设置过滤**：后端发通知前统一判定范围（派发会话 / 定时任务）与事件（需要审批、回合结束、出错退出），两者都开才发；关掉「回合结束」后派发会话回合完成不再弹横幅，审批请求仍会弹。终端会话一档后端尚无产生通知的路径，在设置里置灰并写明。

### 修复
- **外观里的「本地…」点不动**：壁纸模式为「关闭」（线上默认值）时整个图片行被禁用，点按钮毫无反应，选不了图。现在关闭档也能选图，选中预设 / 本地文件 / URL 会自动把壁纸开到「壁纸」档——挑图这个动作本身就表达了要用壁纸，要求先盲开再挑是把顺序颠倒了。参数滑杆仍在关闭档禁用。
- **设置里的行会被反复重建**：行组件原先定义在设置组件内部，每次渲染都是新的组件类型，React 会把整棵子树卸载重建，可能把已打开的系统文件选择器一并关掉。已提到模块顶层，实测重渲染时行与文件输入框的 DOM 节点被复用。
- **「本地…」改为 label 包裹的文件输入**：不再依赖按钮里程序化调用 `input.click()`，改由 label 的原生激活行为打开系统选择器；程序化 click 在部分 WebKit 与自动化环境下会被判定为非用户手势而静默失效。
