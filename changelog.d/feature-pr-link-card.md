- **PR / MR 链接卡片**：会话回放里出现 PR/MR 时渲染成一条可点击的卡片（平台图标 + 编号 + 仓库路径 + 创建时间与更新次数），点击在新标签打开。同一个 PR 的多条记录合并为一张卡，只显示累计更新次数与最近时间。
