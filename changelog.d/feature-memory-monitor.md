### 新增

- **系统监控 · 状态栏**：状态栏新增内存指示（压力色点 + 「Swap 15.9/17.4G · 91%」）与 CPU 指示（「CPU 33%」）。内存等级直接取内核压力信号，CPU 按「用户 + 系统」对照阈值（默认黄 60% / 红 85%），两者都要连续 N 次超阈值才变色；采样失败时显示虚线圆点和「采样失败」。
- **系统监控 · 弹窗**：点任一指示打开「内存 / CPU」两 tab 弹窗。内存 tab 有物理内存四段条（应用占用 / 压缩器 / 可回收缓存 / 真空闲）和 swap 条；CPU tab 有用户 / 系统 / 空闲条、1/5/15 分钟负载和核心数。两个 tab 都按进程树把进程聚合到应用排行，可展开到进程，并给出按规则匹配的处置建议（不调 LLM）。
- **系统监控 · 就地处置**：弹窗里璇玑派发会话的进程行带「关闭会话以释放 ≈N」，复用看板的关闭确认；终端会话只读。
- **会话卡片占用数字**：卡片右上角显示该会话进程树的内存（默认始终显示）和 CPU（默认只在偏高时显示）；点数字打开弹窗对应 tab，并展开、高亮、滚动到该会话的进程行。
- **设置 › 系统监控**：新增分组，可设内存 / CPU 监控开关、采样间隔（5/10/30/60s）、变色防抖次数、无人查看时暂停采样、CPU 黄 / 红阈值（黄 ≥ 红时拒绝保存），以及卡片显示内存 / CPU 的方式（始终 / 偏高时 / 不显示）。
