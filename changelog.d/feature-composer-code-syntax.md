- **派发输入框代码语法**：输入框现在边打边高亮行内代码 `` `x` `` 与代码块 ```` ``` ````，配色与发出后消息区的代码块一致；未闭合的围栏用琥珀描边提示还差一条收尾 ``` ````。

### 变更

- **代码块内 Enter 改为换行**：光标位于 ``` 代码块内部时 Enter 不再发送消息而是换行，底栏提示同步变为「代码块内 · Enter 换行 · 移出代码块或点发送」；代码块之外的 Enter 行为不变，仍是发送。
- **发出后仍是代码块**：派发页气泡与会话回放里的用户消息现在会把 `` `x` `` 渲染成行内代码、把 ```` ``` ```` 渲染成带复制按钮的代码块（此前原样显示成一串反引号）；只渲染代码语法，`#`、`*`、路径等其余字符仍按字面原样保留，多行换行也照旧不折叠。
