### 新增
- **经验页按项目筛选**:顶部新增项目筛选条(与会话页同款彩色胶囊,带条数),点一下只看该项目的经验,再点一次回到全部;条数最多的 5 个项目直接列出,其余在「其余 N 个」下拉里。
- **经验页快捷键**:⌘F(跟随设置里的「页内查找」键位)聚焦搜索框,↑↓ 换条,E 编辑当前经验,⌘Enter 保存。
- **编辑经验**:在正文栏原地修改类型、索引摘要、描述和正文。索引摘要就是 `MEMORY.md` 里那一行,会话启动时注入上下文的是它。文件在编辑期间被别处改过时不会直接覆盖,由你选择载入最新或用自己的版本覆盖。
- **删除经验与回收站**:删除会把文件移入 `~/.xuanji/trash/memory/` 并移除 `MEMORY.md` 里的索引行,删除后可立即撤销,也可以之后在「回收站」里恢复;确认框会列出还有哪些经验在引用它。
- **共享经验的处理**:软链到共享库的经验带「共享 · N 个项目」标记;编辑前提示会波及哪些项目,删除时默认只从当前项目卸载,也可选择连同共享库里的文件一起删除。

### 变更
- **经验页改为列表 / 正文双栏**:原来按项目纵向堆叠、点开抽屉才能看正文;现在左侧列表、右侧常驻正文,换条即换正文,列表与正文各自滚动,搜索框始终可见。窗口宽度不足 900px 时仍用抽屉看正文。
- **经验正文按 Markdown 渲染**:加粗、行内代码、列表、表格、代码块不再显示为原始符号;`[[名字]]` 变成可点的链接,点击跳到那条经验。
- **搜索结果高亮命中**:名称、描述和正文里的命中处高亮,正文自动滚到第一处;命中只在正文里时,列表里显示正文片段。搜索范围跟随所选项目,并提示其它项目还有多少条命中。
