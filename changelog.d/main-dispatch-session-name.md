- **派发页会话标识**：从会话看板进入某会话后，派发页页头此前不显示会话名，只能靠聊天流里会滚走的 resume 提示辨认；现在常驻当前窗口绑定会话的 名称 + 会话 id，随会话生命周期存在：resume 即显示、新会话白纸隐藏、跨目录交接/首条消息先显「未命名会话」、首轮回复结束后回填自动命名。会话名字号 0.9375rem，并以**所属项目的锁明度分类色「荧光」呈现**（叠一层同色低透光晕，呼应「数据是唯一发光的东西」的北极星）——项目身份编码进名称颜色后，原先的项目芯片不再单列（项目路径退到悬停 title，term-line 另有蓝色 cwd 兜底）；未命名态转 faint 中性、去光晕以区分「待命名」。原型另附位置对比开关（顶部页头 / 输入框上 / 输入框下）供取舍，默认顶部。
