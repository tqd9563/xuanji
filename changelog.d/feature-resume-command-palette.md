### 新增

- **/resume 命令恢复已关闭会话**：派发页输入 `/resume` 回车弹出居中面板，列出当前项目下被看板「×」关闭过的会话（名称 + 短 id + 关闭时间），↑↓ 选择、Enter 续接、Esc 关闭；选中后自动做所有权预检 → 取消隐藏（卡片回到会话看板）→ 装载历史上下文，发送第一条消息即原地续接。
- **后端已关闭会话接口**：`GET /api/sessions/closed?cwd=` 返回隐藏会话清单（自有 dispatches 表优先、agents CLI 补全终端来源、改名覆盖生效、按项目过滤、元数据不可寻的不展示）；`POST /api/sessions/:id/unhide` 为看板关闭的逆操作，仅删自有 SQLite 隐藏行，`~/.claude` 不涉及。
