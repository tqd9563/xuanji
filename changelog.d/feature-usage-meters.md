### 变更

- **用量条**：派发页状态条的 Context / Usage / Weekly 三条用量轨由 5px×52px 加厚到 10px×88px，填充比例在深色底上可直接读出；轨上新增一道亮刻度标出「此刻在配额窗口中的位置」，填充越过刻度即表示用量领先于时间（烧超）。Context 无重置窗口，不画刻度。
- **重置倒计时**：5 小时 / 7 天窗口的重置倒计时从悬停 tooltip 移到轨后常驻显示（`2h41m` / `3d4h` 形式），不再需要把鼠标停上去看；移动端此前根本无法触发悬停，现在直接可见。倒计时按 30s 心跳自走，不再依赖流式事件顺带重渲染。
- **窄屏用量条**：≤430px 下隐去 Context/Usage/Weekly 文字标签（完整信息保留在 title），腾出的宽度给条与倒计时，三段不再被挤出可视区靠横滑才能看全。
