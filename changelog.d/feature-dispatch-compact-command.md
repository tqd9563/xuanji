### 新增
- **派发框支持 `/compact` 压缩上下文**：在派发输入框内输入 `/compact` 并发送，与其它未被拦截的文本一样直接透传给底层 Agent SDK streaming-input 队列，由其内部 `claude` CLI 子进程识别为内置压缩命令（实测确认：SDK 的 `Query` 控制协议本身不提供 `compact()` 方法，压缩是 CLI 对该字面文本的内置识别，走的是普通 user message 通道，非控制请求）；压缩期间看板显示"正在压缩上下文…"，压缩完成后在对话流里追加一条压缩结果提示（含压缩前后 token 数），失败（如消息数不足)时沿用 SDK 原有的合成回复文本，不重复报错。
