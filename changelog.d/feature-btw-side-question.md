### 新增

- **旁路提问(/btw)**：主对话在跑也能「顺便问一句」。输入框以 `/btw` 开头（或按 `⌘/`）提问，后端复用该会话的 Agent SDK 句柄发一次 side_question 控制请求——与 CLI 的 `/btw` 面板同一条协议：模型拿着主对话全部上下文单次直答、不许用工具，答案落在派发页右侧停靠的旁路面板，**不进主对话、不占它的 context、不打断它正在跑的回合**。输入框以 `/btw` 开头时上方现出紫色「旁路提问 · 不进主对话」标记，发送键变为「问旁路」。
- **旁路记录自动保存**：CLI 自己不落盘 side question（答案只活在 CLI 进程内存，关面板即没），璇玑把每一问一答存进自有 SQLite 的 `side_questions` 表，按会话挂载；关掉面板、刷新页面、换个 tab 接回都还在。面板内 `⇧←` / `⇧→` 翻记录，`≡` 打开可搜索的记录列表；状态条新增「旁路 N」计数芯片，点它随时重开面板停在最后一条答案。`⌘/` 是一个来回切的开关：按一下开面板并让输入框进入 `/btw` 紫色旁路模式（已有内容自动加前缀、光标落到末尾），再按一下去掉前缀回到普通会话模式并关闭面板。
- **旁路答案的三个出口**：「复制」；「存为经验」把这一问一答写成当前项目的一条 reference memory（写 `~/.claude/projects/<项目>/memory/`，弹确认、同名不覆盖、追加 MEMORY.md 索引，属架构铁律 2 的例外①）；「钉入主对话」把问与答作为你的下一条消息发进主对话——这是旁路内容进入主对话的唯一路径，主对话正在跑时禁用。
- **快捷键表新增「旁路提问」**（默认 `⌘/`，设置里可改）。

### 变更

- **派发页布局**：旁路面板打开时主对话区、状态条、输入框与终端行整体收窄为左栏（右栏固定 400px，窄屏 340px），状态条里的用量条随之缩短；关闭面板即恢复原布局。移动端本次不提供旁路面板。
