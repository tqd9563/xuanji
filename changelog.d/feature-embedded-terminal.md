### 新增

- **全局终端**：任意视图按 ⌘` 呼出、再按收起的悬浮终端，跑的是本机真实的 zsh（node-pty + xterm.js），别名、插件、p10k 提示符与 Ghostty 里一致；支持多标签、拖拽调高、最大化，切视图与刷新页面都不丢会话，重新打开时回放最近输出。
- **终端外观跟随 Ghostty**：默认读取本机 Ghostty 配置的主题（Catppuccin Frappe）、字号、背景透明度与模糊、光标样式；字体按 Ghostty 实际渲染的来（配置写的 Maple Mono NF CN 未安装时用其回退的 JetBrains Mono）。起 shell 的命令也跟随 Ghostty 的 `command`。
- **设置 › 终端**：外观来源（跟随 Ghostty / 自定义）、配色主题（Catppuccin 四款与璇玑玉色）、背景颜色 / 不透明度 / 模糊 / 背景图片、字号、光标；新终端默认目录（跟随会话 / 上次目录 / 家目录）与切换视图时保持或收起。
- **快捷键冲突检测**：「呼出 / 收起」一行标出同样占用该组合的 Ghostty 全局热键与 macOS 系统快捷键，并说明去哪里改。
- **状态栏终端指示器**：显示「终端 未开 / N 个 / N 在跑」，点击等同 ⌘`；在派发页新开终端时目录默认是当前会话的 worktree。

### 安全

- **终端只对本机开放**：终端接口与 WebSocket 只接受本机直连，经 Tailscale serve 等反向代理、Host 非本机、或来自其它网站 Origin 的请求一律拒绝，手机端不显示终端入口。
